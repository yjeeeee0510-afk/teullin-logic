# 물건 누끼 도구

사용자가 준 물건 모음 사진(흰 바탕)에서 물건을 하나씩 잘라 투명 배경 그림으로 만든다.

- `cut.py` — 모음 사진 속 물건마다의 위치(상자)와 1차 모양 따기
- `matte.py` — 흰 물건·구멍 뚫기 예외 목록
- `matte3.py` — 최종 누끼: 트라이맵 → 색 분리 알파 → 가이디드 필터로 경계 다듬기 → 흰 테두리 색 걷어내기, 물건별 받침·그림자 제거
- `qa.py` — 검수: 물건마다 12가지 바탕(검정·흰·빨강·초록·파랑·노랑·보라·회색 + 지역 땅 4) 위에 올린 표

모음 사진(flower.png, sea.png, sky.png, night.png, snow.png, sea2.png)은 저장소에 없고 작업 폴더에 둔다.
결과는 높이 260px(선착장 420px) WebP로 `img/sprites/`에 넣고 `index.html`의 `SPR_WEBP`와 `sw.js` 목록을 맞춘다.
