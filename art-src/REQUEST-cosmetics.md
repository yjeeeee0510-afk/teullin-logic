## 받은 뒤 처리 (Claude)
- 쌍·소품·받침: 단색 바탕 누끼(`tools/matting/chroma.py`, `cols`는 쌍 2·소품/받침 3) → 쌍은 높이 약 600px 웹피 → `img/` 파일로 두고 프로필을 열 때만 받음. 검수표(분홍·남색·흰색 바탕)를 사용자에게 보여 준 뒤 넣는다(누끼 품질 기준).
- 카드 배경: 크기 맞춤·용량 줄임 후 `img/`에.
- 새 파일은 `sw.js` CORE 목록과 `ASSET_V`/`AV`를 맞춘다.
- 쌍 파일 이름은 `pair<작은번호>_<큰번호>` (예: `pair2_3` = 어흥이+깡총이). 게임은 내 캐릭터와 동행 친구 번호로 이 파일을 찾고, 없으면 지금처럼 코드로 합성한다.
